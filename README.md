# LeXi

### 想懂的那个词，随手一查。

**词典的扎实，AI 的新鲜。** 从经典用法到网络新词，从日常英语到专业术语，LeXi 把中英释义、整段翻译和发音装进一个轻巧的桌面窗口。Windows 与 macOS 共用同一套查询核心，界面各自原生。

## 一个输入框，什么都能查

- **不用选模式。** 单词、短语、整段文字直接输入，LeXi 自动判断是查词还是翻译，也自动判断中英方向。
- **边打边提示。** 候选词随输入出现，方向键预览、Tab 选用、Esc 还原。
- **整段翻译。** 一次最多 5000 字，保留段落、大小写、数字和编号，一键复制。

## 词典的扎实

- **多部离线词库联合查询。** ECDICT 英汉、Open English WordNet 英英、CC-CEDICT 汉英、教育部《重編國語辭典修訂本》，以及国家教育研究院的海事、造船、计算机、两岸计算机译名、电机、物理、数学术语。没网也能查。
- **简繁都能查。** 用简体查繁体词库；两岸不同的叫法分别标注，各自都能检索。
- **词形一眼看全。** 输入 went 也能找到 go；过去式、分词、复数、比较级排成一行，右键复制。
- **在线词典补全。** 英文与中文的 Wiktionary 词条、英语音标、词形和词源自动补上，附原文和链接。
- **原文永远在。** 每部词典的原始条目都保留，随时展开核对。

## AI 的新鲜

- **两个模型同时查。** 先到的先显示，生成中的释义实时出现并清楚标注；一个模型出错，另一个的结果照常保留。
- **义项自动整理。** 重复的说法合并成一条，不同的含义各自保留；每种原始表述都能展开查看。
- **TL;DR 一句话。** 先看核心含义，再按需读完整释义、例句和参考资料。
- **新词、俚语、专业术语都接得住。** 网络流行语、加密资产、区块链、密码学和信息安全的专门含义都有覆盖，领域标签清楚。
- **来源说得清。** 有词典依据的释义附编号链接；模型补充的内容单独说明；AI 给出的音标和词形另行标注，绝不冒充词典。

## 用你已有的订阅

- **无需额外账号。** 直接使用本机 ChatGPT（Codex）和 Claude（Claude Code）的订阅，不用另买 API。
- **登录交给官方。** 授权在官方客户端里完成，LeXi 不读取、不保存令牌。macOS 上还能直接用 ChatGPT 与 Claude 桌面应用自带的客户端。
- **模型随你配。** 主要模型、第二模型和义项判断模型都可以在设置里选。

## 听见怎么读

- **系统声线即开即用。** Windows 本地发音、macOS 系统声线，按文字语言自动选择中文或英文。
- **在线语音任你接。** OpenAI、Grok、ElevenLabs：选模型、选声线、先试听；ElevenLabs 还能读取你账号里的声线，或直接填写 Voice ID。
- **密钥只在本机。** API Key 在 Windows 上以当前用户加密保存，在 macOS 上存入钥匙串。生成过的发音按声线缓存，离线也能再听。

## 快，而且稳

- **进度看得见。** 状态环展示词典、补充、合并、完成四个阶段，完成或未完成一目了然，不编造百分比和剩余时间。
- **查过就留下。** 完整结果自动保存，再次打开不必联网；想更新时点“重新生成”。
- **在线、离线一键切换。** 离线时照样使用本地词库和已保存的结果。
- **来回不迷路。** 查询历史、后退和前进，随时回到刚才那个词。

## 两个平台，同样好用

| | Windows | macOS |
|---|---|---|
| 界面 | 原生 WPF，Windows 11 磨砂背景，托盘常驻 | SwiftUI 与 Liquid Glass，macOS 26 及以上 |
| 快速切回 | 固定到任务栏第 2 位，Win+2 | Dock 与 ⌘Tab，关闭窗口不退出 |
| 快捷键 | Enter 查询 · Ctrl+L · Ctrl+, · Alt+← / → | Return 查询 · ⌘L · ⌘, · ⌘[ / ⌘] · ⌘Y |
| 安装 | [构建与运行](docs/guide.md) | [从源码构建](apple/README.md) |

两个版本使用同一份查询核心：释义、合并、来源说明和状态文字完全一致。逐项对照见 [FEATURES.md](FEATURES.md)。

## 你的数据，留在你的电脑

不需要注册，没有统计上报。查询历史、缓存和设置都存在本机；联网只用于 Wiktionary、你选择的模型和语音服务。源码以 MIT 协议开放，词典数据保留各自的来源与许可。
