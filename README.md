# LeXi

### 想懂的那个词，随手一查。

**词典的扎实，AI 的新鲜。** 从经典用法到网络新词，从日常英语到科技术语，LeXi 把中英释义放进一个轻巧的桌面浮窗。

## 看懂，也会用

- **一眼抓住词义。** 双语释义、清楚的词性、音标和词形变化，例句按需展开。
- **新词不掉队。** 两个模型同时补充，再整理重复义项；原始来源和不同表述都能回看。
- **专业一点，也接得住。** 多部离线词库覆盖英语、中文、计算机、电机工程、物理、数学与航海术语。
- **一段话，也能查。** 自动识别词语与文本，直接给出释义或翻译。
- **听见怎么读。** 内置本地发音，也可连接在线语音服务。
- **用完就收起。** 粉色点缀、磨砂背景、键盘操作。Windows 固定到任务栏，Win+2 随时切回；macOS 使用 Liquid Glass 工具栏与快捷键。

## 你的桌面，你的选择

离线可用，联网按需开启。可连接自己的 ChatGPT / Claude 订阅，LeXi 无需额外账号。模型补充与词典原文保留清楚的来源说明；登录由官方客户端管理。

**支持 Windows 与 macOS 26 及以上版本。** macOS 版目前需要从源码构建（[说明](apple/README.md)），两个平台的功能对照见 [FEATURES.md](FEATURES.md)。源码以 MIT 协议开放。
