# 干净分发准备

分发格式：Windows x64 免安装 ZIP，自带 .NET 运行环境。只有明确运行 `scripts/Package.ps1` 才生成，不上传、不创建 GitHub Release。

构建只从源码发布到 `artifacts/Lexi-clean`，每次清空受控的纯程序目录。发现用户数据或链接即拒绝清理；旧的 `artifacts/Lexi` 和正在使用的安装目录均不作为分发源。程序文件、公开资源和 Git 跟踪文档进入包，个人词库由接收者另行安装。

源码默认 API 地址已留空。用户保存的地址、模型选择、凭据、历史、语音和释义缓存只存在本机用户数据区；Windows 密钥由当前用户保护，macOS 密钥存入 Keychain。官方 OAuth 登录不由 LeXi 复制或打包。

分发脚本先执行回归和源码隐私检查，再自包含构建，禁止 PDB、userdata/data、密钥目录、历史、日志和临时文件；扫描应用程序集和文本中的个人路径及已知敏感模式。ZIP 解压后再检查一次，输出 SHA-256。模式扫描无法证明任意未知秘密不存在，发布前仍应审查新增默认配置与资源。

本次仅准备流程，没有生成对外 ZIP 或 Release。已有安装包未做逆向解包审计；发现的是可复用构建目录残留公共词库和符号文件的风险，没有发现凭据已被分发的证据。macOS 开发构建仍需正式签名、公证后再向一般用户发布。

分享时不要直接压缩自己的安装文件夹，其中的 userdata/data 是个人数据。升级继续保留原有用户数据，分发接收者第一次运行应从空设置开始。
