# 自定义文本服务

Windows 与 macOS 可直接连接 OpenAI Chat Completions 兼容服务，用于查词、翻译和义项整理。

1. 打开设置的“账号连接”（Windows）或“账号”（macOS），找到“自定义文本服务”。
2. 填写 Base URL，默认 `https://api.example.org/v1`。这是接口根地址，程序只追加 `models` 或 `chat/completions`，不会再追加 `/v1`。
3. 填写服务提供的 CF Access Client ID 与 Client Secret。额外的 API Key 可留空。三个字段都只保存在本机平台安全存储中，普通设置不包含这些值。
4. 点击“读取模型列表”。鉴权成功后，由服务端提供可选模型。程序不会猜测或自动选择一个模型。
5. Windows 返回“查询与模型”选择主要模型、第二模型或义项判断模型，再保存设置。macOS 先保存连接，再返回“查询”选择模型。

“逐片显示生成结果”使用 SSE；关闭后请求普通 JSON。已有查询结果照常恢复；希望改用新模型处理查过的词时，点击“重新生成”。更换地址后，需要为新地址填写或保存凭据。

每次请求都带有 CF Access 的两个鉴权头与 `LeXi/版本号` 的 User-Agent。填写可选 API Key 后，额外携带 Bearer 鉴权。401/403 会直接报告鉴权失败，程序不尝试匿名请求、不跟随重定向，也不自动切换服务或模型。

凭据在 Windows 使用当前用户加密，在 macOS 使用 Keychain，并按完整接口地址绑定。macOS 本地 Host 只在进程内接收这些值，退出后清除。临时签名的 macOS 构建可能需要重新填写并保存凭据。请勿把真实凭据放入设置文件、日志、截图或问题报告。

此入口只提供文本推理。发音在“发音”中独立选择服务；自定义文本服务不会收到 `/audio/speech` 请求。

当前更新覆盖 Windows/macOS，未修改独立开发中的 iOS 分支。离线回归使用合成凭据和模拟服务；真实服务需由用户在应用内填写凭据后验证。
